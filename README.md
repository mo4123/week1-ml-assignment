# Week 1 ML assignment

The assignment is in `week1_assignment.py`. It prints Pandas `info()` and `describe()`, fills missing Age values with the median and Fare values with the mean, encodes Sex with LabelEncoder and Embarked with OneHotEncoder, plots passenger ages, and saves `titanic_cleaned.csv`.

1. Download **Titanic: Machine Learning from Disaster** `train.csv` from Kaggle and put it in this folder.
2. Install dependencies: `pip install pandas matplotlib scikit-learn`
3. Run: `python week1_assignment.py`
4. Submit the script, `titanic_cleaned.csv`, and `age_distribution.png`.

The separate `practice_set.py` covers the four questions in `practice set(1).pdf`. Put a CSV with `area` and `price` columns here as `housing.csv`, then run `python practice_set.py`. It reports R² and mean absolute error and prompts for a house area. R² is a regression metric, not classification accuracy.

Dataset source: https://www.kaggle.com/c/titanic/data
